Meta 在 2026 年 10 月发布新一代 Muse Wonder 系列模型。InfoQ 文章认为，这不仅是一次模型升级，也标志着 Meta 试图凭借“个人超级智能”和消费级 Agent 路线重新回到 AI 前沿。文章前半部分介绍 Muse Wonder 的模型能力，后半部分整理了 Meta 超级智能实验室负责人 Alexandr Wang 的访谈，解释 Muse 为什么能在短时间内获得关注，以及 Meta 如何重建 AI 组织。

**Muse Wonder 的核心：主动记忆与主动专注**

Muse Wonder 和 Muse Wonder Full 的定位不是普通聊天机器人，而是能够长期理解用户、持续推进目标并代表用户完成任务的个人 Agent。Meta 将两项能力作为核心卖点：

- **主动记忆**：跨对话保存与用户有关的重要信息，并在后续任务中主动判断哪些信息值得调用，而不是简单地把越来越长的历史上下文塞进提示词。模型在推理阶段支持最高 100 万 Token 上下文，输入包括文本、图像、视频和音频。
- **主动专注**：面对障碍时继续寻找替代方案，随着新信息出现调整计划；需要信息时主动向用户澄清，在采取重要行动前请求确认。它针对的是 Agent 经常“做几步就停”或遇到异常便失效的问题。

文章将这两项能力概括为下一代个人 Agent 的基本形态：既要长期了解一个人，也要围绕这个人的目标持续工作。Coding 被视为检验两者的综合场景，因为真实开发需要模型跨文件记忆需求，反复经历“修改—测试—失败—再修改”的循环。

**模型评测、产品定价与局限**

Meta 介绍了 MemoryBench、FocusBench 和 SWE-Marathon 等测试。文章引用的结果显示，Muse Wonder 系列在长上下文记忆、持续执行和部分长程软件工程任务上具有竞争力；在 Meta 自己整合的 Personal Superintelligence Index（PSI）中，Wonder Full 的得分也高于文中列出的几款对比模型。不过，Muse 并非所有测试都领先，例如部分代码基准仍落后于竞争模型，而且不同结果使用的模型版本、Agent 产品和 Harness 并不完全相同，不能简单视为严格的同条件对照实验。

Muse Wonder 通过 Meta Model API 和 Muse Code 开放，价格为每百万输入 Token 4 美元、缓存输入 0.2 美元、输出 20 美元；Wonder Full 暂未单独提供 API 定价，包含在 Muse Code 每月 50 美元和 200 美元的订阅档位中。产品随后会逐步进入 Muse，优先面向订阅用户处理 Artifact 生成和复杂任务。

由于 Agent 将接触邮件、日历、文件并可能采取现实行动，Meta 对安全问题的要求高于普通聊天模型。文章提到，Wonder Full 在未经缓解时可能触及公司定义的化学和生物高风险阈值，因此增加了安全后训练和系统级分类器；对于不可逆操作，Meta 建议保留人工确认。模型目前仍可能在多步推理的新颖场景中出错，3D 精确视觉和空间推理也是已知弱项，量化方式、服务配置、提示词、工具与 Agent Harness 都会显著影响表现。

**从 OpenClaw 原型到七个月发布**

Alexandr Wang 回忆，Muse 的产品想法受到早期 OpenClaw 使用体验启发。他与 Nat Friedman 深度使用个人 Agent 后，意识到这类产品可能成为一种“终极消费产品”，并分别向 Meta 董事会提交备忘录。团队用一到两周做出了第一个原型，原型很快展示出令人惊讶的能力，但经常故障；从原型到正式发布又花了七个月，把不稳定的演示品打磨成团队敢于交给普通消费者的产品。

团队规模始终控制在 200 人以内。为了判断模型何时真正具备发布条件，团队列出超过 100 项个人 Agent 必须具备的能力，并为每一项设定阈值。早期检查点可能只有部分项目达标，直到专门训练的 Musepark 1.3 检查点第一次实现“全部变绿”，同时内部实际使用体验也明显超过此前版本，团队才认为产品准备就绪。Wang 认为，关键并不只是模型本身，而是把模型、产品设计、新手引导、可靠性和安全机制磨成一个统一的消费体验。

**靠“哇时刻”和 Meme 获得增长**

Wang 认为，普通用户从聊天机器人过渡到 Agent，需要通过新手引导理解它究竟能做什么。Muse 的增长首先依赖让用户尽快遇到“哇时刻”，随后把真实使用案例传播出去。与只介绍公司和技术的传统广告相比，转发用户如何让 Muse 解决现实问题更有效；文章举例称，用户甚至可以把证件遗落后的取回流程交给 Agent，让它协调快递、安保和办公室交付。

Meta 还利用了 Jolly 吉祥物和 Meme 文化。Wang 在 X 上大量转发用户案例并亲自创作 Meme，希望让 Muse 穿透 AI 信息洪流，同时让 Meta 重新变得有趣、具有文化影响力。Jolly 出现在对话截图中，使截图本身成为可识别、可转发的产品广告。文章把这种传播方式总结为“产品必须在截图里也成立”。

用户留存则依赖逐步建立信任：先交给 Agent 一个很小的任务，确认它能完成后，再逐渐增加任务难度和授权范围。每一次可靠完成都会让用户愿意把更大的问题交给它，形成从好奇到信任、再到长期使用的递进过程。Wang 将 Muse 描述为“第二大脑”，认为个人 Agent 的长期价值在于帮助人们处理生活中的障碍，把注意力重新放回真正想做的事情上。

**Wang 加入 Meta 与 AI 组织重建**

Llama 4 之后，Mark Zuckerberg 与 Wang 联系，希望听取他对 Meta AI 战略的建议。双方从首次接触到宣布交易只用了约五到六周。最终安排是 Meta 投资 Scale AI 并持有 49% 股份，Scale 保持独立运营，而 Wang 等人加入 Meta。Wang 认为，Meta 真正需要的并不只是 Scale 的业务，而是重新搭建 Llama 和整体 AI 项目所需的人才与组织。

Meta Superintelligence Labs（MSL）的组织原则是小团队、扁平结构、高技术导向和极高人才密度，并围绕“个人超级智能”建立清晰使命。Meta 同时提供算力、基础设施和庞大分发渠道，使团队能够避开创业公司的常见瓶颈；但组织仍保持足够开放，让顶尖研究员可以留下自己的判断。Wang 在 Meta 的角色也从 Scale 时的“作者”转为“教练”：不再试图亲自决定每一个细节，而是确定北极星方向、招募顶尖人才、提供环境和资源，让他们自行探索。

他把研究型组织比作“挖钻石”，而把数据标注、配送等成熟业务比作“盖摩天楼”。前者的回报呈幂律分布，大多数尝试可能失败，少数成功却能带来极高回报，因此需要容纳试错、支持少数真正有潜力的方向；后者则依靠流程、运营和持续的小幅效率提升。Wang 认为，MSL 当前更接近前者，管理重点不是微观控制，而是保护一个让聪明人做出最好工作的环境。

文章最后呈现了 Meta 重返 AI 竞争的两条主线：模型层面，把主动记忆、长程执行和专业 Agent 能力写入基础模型；产品层面，把 Muse 做成真正能替用户办事的个人 Agent。Meta 希望利用每天触达数十亿用户的消费产品生态，将“个人超级智能”从实验室能力转化为大众产品，但其成败仍取决于长期可靠性、隐私信任、安全边界和模型在真实世界中的稳定执行能力。
